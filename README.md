# סטנגה בשכונה ⚽

משחק השכונות של שנות ה-90, בתלת-מימד ובדפדפן: חצר של שיכון, אספלט ישן עם בורות, דודי שמש, חבלי כביסה, גרפיטי ושני ילדים שחזרו הרגע מבית הספר.

**לשחק:** https://amal-ramot.github.io/stanga/

## החוקים (לפי ויקיפדיה)
- כל שחקן נוגע בכדור **פעם אחת בתור**. נגיעה כפולה = בעיטת עונשין ליריב מקו האמצע.
- מותר להקפיץ שוב אם הכדור לא נגע ברצפה.
- ניקוד: גול 1 · קורה 2 · משקוף 3 · גול בעקב 4 · מספרת 5 · בין הרגליים 10.

## שליטה
| | שחקן 1 | שחקן 2 |
|---|---|---|
| תנועה | WASD | חיצים |
| בעיטה (להחזיק לעוצמה) | רווח | Enter |
| הרמה | Shift שמאלי | Shift ימני |
| עקב | E | / |
| מספרת | Q | . |

בטלפון: ג'ויסטיק וכפתורים על המסך.

## טכנולוגיה
- [Three.js](https://threejs.org) r180 עם `WebGPURenderer` (WebGPU, ונפילה אוטומטית ל-WebGL2)
- צללים רכים, הצללה סביבתית (GTAO), תאורת HDRI
- טקסטורות, מודלים ו-HDRI מ-[Poly Haven](https://polyhaven.com) (CC0), ראו `assets/CREDITS.md`
- סאונד מסונתז ב-WebAudio: מכוניות, ציפורים, כלב, ורדיו מהמרפסת עם מוזיקה מקורית
